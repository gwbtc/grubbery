About this nexus

    
This nexus is a consolidated endpoint for the Anthropic API — a local, well-structured stand-in for the external service, ideally used as the ship's only door to it. Apps that go through it never hold the key or reach the internet; they are granted this nexus's road, which makes “may use Claude” an ordinary capability, and every use is metered to its caller.
