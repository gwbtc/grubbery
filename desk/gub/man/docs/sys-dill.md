# /sys/dill

The terminal is two kinds of grub. `logs.dill-told` holds the ship's log
output, written on every told from dill. Each session is a grub under
`/sys/dill/sessions` holding its blits, subscribed at boot for every
session dill reports. A belt in is a poke to `/sys/dill/main.sig` naming
the session.
