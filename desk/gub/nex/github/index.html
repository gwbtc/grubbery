About this nexus

    
This nexus is a consolidated endpoint for GitHub — a local, well-structured stand-in for the external service, ideally used as the ship's only door to it. Apps that go through it never hold credentials or reach the internet; they are granted this nexus's road, which makes “may use GitHub” an ordinary capability like any other.
