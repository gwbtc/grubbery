# /sys/scry

A fiber cannot scry. `/sys/scry/main.sig` takes a scry request as a poke,
runs it in the agent, and pokes the result back under the mark the fiber
named, so the answer hydrates through the mark pipeline like any poke.
The same grub is the door to the remote-scry farm: grow, tomb, and cull
publish and retract pages, and a keen reads another ship's farm, its
answer poked back under `%keen-response` on the fiber's wire. The state
grub records outstanding keens by wire so a yawn cancels exactly the
caller's.
