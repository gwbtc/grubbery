Tools

The tools of one tools nexus: the one at the path above, whose code namespace is <path>/code/lib/tools. A tool is one Hoon file compiled to a tool; its name is its file name with hyphens as underscores. Click one for its schema, source, and a form to run it. Any nexus can mount a tools nexus of its own; this page shows whichever one its URL names, /grubbery/mcp/<path>.

Runs

Every tool call in flight in this tools nexus, one grub each under its runs/. A run's fiber executes the handler and writes the result into its own grub; the caller reads it and culls the grub. What stays here is what no caller has collected.
