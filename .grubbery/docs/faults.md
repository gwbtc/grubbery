# Faults

Identified wrong behaviours, each with the change that would fix it and
where that change stands. An entry is a problem, not a pull request: it
exists before any PR and outlives one that is closed. The status line
points at the PR when there is one.

Each entry has three parts. **Problem** is what a ship does wrong and the
mechanism that makes it do that. **Proposed solution** is the change, in
a sentence or two. **Status** is open, a PR number, landed, or rejected
with the reason.
