workspace

Five things composed here, all served as files from web-test/ui/: a horizontal <split-view> (sidebar), a vertical one (the console below — drag its top edge), a <tab-group> here and in the console, a <drop-menu> and <modal-dialog> up top, and a shared Feather icon sprite.

Drag either divider to resize. Collapse the sidebar with the ☰. Everything remembers its state across reloads.

panels

Each tab is a slotted child tagged with tab-label. No framework, no build — one .js file per component.

events

The status line up top logs each component's "state out" events — resize, collapse, tab change, menu pick, modal result.
