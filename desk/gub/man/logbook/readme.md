# Logbook

Accepts txt pokes, appends lines to `main.txt`. Mirror grub for cross-ship mirroring.

## Files

- `main.txt` — Log file. Poke with txt to append lines.
- `mirror.sig` — Mirror process. Poke with ship name (e.g. `~nec`) to start mirroring.

## Directories

- `mirrored/` — Mirrored `main.txt` from a remote ship.
